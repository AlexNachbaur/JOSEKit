# Source of these vectors

The JSON files in this directory are copied unmodified from the JOSE working group's
machine-readable cookbook, <https://github.com/ietf-jose/cookbook>, at commit `13692b6`. They
are the examples of RFC 7520 ("Examples of Protecting Content Using JSON Object Signing and
Encryption"), plus the repository's RFC 7797 (`rfc7797/`) and RFC 8037 (`curve25519/`)
examples.

The cookbook is released under the Unlicense; its `LICENSE` is kept alongside. Do not edit
these files. To update them, copy a newer commit over them and record it here.
